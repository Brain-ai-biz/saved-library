# הספרייה של השמורים

**כל מה ששמרת באינסטגרם ולא חזרת אליו, מסודר על מדפים.** הכלי קורא את התיקייה "שמורים" שלך בקריאה בלבד, ממיין למדפים לפי נושא, מסכם כל פוסט במשפט אחד, ומוציא רשימה של מה ששווה באמת לעשות. בסוף נפתח במחשב דף שבו קיר השמורים מתפרק ועף למדפים, עם חיפוש וכרטיס לשיתוף.

- **עלות:** אפס. בלי מפתח API ובלי מנוי נוסף. עובד על המנוי שכבר יש לך.
- **בטוח לחשבון:** קריאה בלבד. בלי לייק, בלי שמירה, בלי הסרה ובלי שום לחיצה באינסטגרם.
- **פרטיות:** הכול נשאר במחשב שלך. הכיתובים של הפוסטים עוברים רק לכלי שאיתו עובדים, כדי שיוכל לסכם.
- **צריך:** מחשב (לא טלפון), דפדפן שמחובר לאינסטגרם (כרום הכי פשוט), ופייתון 3.9 ומעלה (במק קיים ברוב המקרים; אם חסר, הכלי יגיד).
- **ואחד מהכלים:** [קלוד קוד](https://claude.com/claude-code) (במנוי Claude Pro ומעלה), [קודקס](https://chatgpt.com/codex) (כלול במנויי ChatGPT בתשלום), או רק ChatGPT עם העלאת קבצים (בחינמי יש מגבלה יומית).
- **במק יכולות לקפוץ שתי הודעות:** בקשה להתקין "כלי שורת פקודה" (בפעם הראשונה שמריצים פייתון), ובקשת גישה לתיקיית ההורדות. בשתיהן מאשרים.

## התקנה

**בקלוד קוד**
1. צריך [Claude Code](https://claude.com/claude-code) מותקן במחשב.
2. פותחים אותו ומדביקים:

> התקן לי את הסקיל "הספרייה של השמורים" מהכתובת https://github.com/Brain-ai-biz/saved-library : הורד את הריפו לתיקיית הסקילים שלך, ~/.claude/skills/saved-library (אם אין git במחשב, הורד את קובץ ה-zip של הריפו וחלץ אותו לשם). אחר כך תקרא את SKILL.md שבתיקייה ותפעל לפיו כדי לסדר לי את השמורים. דבר איתי בעברית.

**בקודקס**

אותו דבר, עם תיקיית הסקילים של קודקס:

> התקן לי את הסקיל "הספרייה של השמורים" מהכתובת https://github.com/Brain-ai-biz/saved-library : הורד את הריפו לתיקיית הסקילים שלך, ~/.agents/skills/saved-library (אם אין git במחשב, הורד את קובץ ה-zip של הריפו וחלץ אותו לשם). אחר כך תקרא את SKILL.md שבתיקייה ותפעל לפיו כדי לסדר לי את השמורים. דבר איתי בעברית.

אם הכלי מבקש אישור להוריד או להריץ פקודה, מאשרים. בפעם הבאה מספיק לפתוח שיחה חדשה ולכתוב `תסדר לי את השמורים`.

**רק ChatGPT**
1. מורידים את [saved-library.zip](https://github.com/Brain-ai-biz/saved-library/releases/latest/download/saved-library.zip) ולוחצים עליו פעמיים. בתיקיית ההורדות נוצרת התיקייה `saved-library`.
2. פותחים את `start.html` שבתיקייה, וקוראים את השמורים עם הכפתור (צעדים 1 ו-2 בדף).
3. בשיחה חדשה ב-ChatGPT מצרפים את הקובץ שירד ואת `chatgpt/saved-library-chatgpt.py`, ומדביקים את הפרומפט מהכפתור בדף (או מ-`chatgpt/prompt.txt`).

## מה קורה אחרי שכותבים "תסדר לי את השמורים"

1. **קריאה:** יש לך את התוסף של Claude לכרום? הכלי קורא לבד. אין? נפתח הדף `start.html`, גוררים כפתור אחד לסרגל הסימניות, ולוחצים עליו באינסטגרם. בערך דקה לכל 100 שמורים.
2. **מיון:** הכלי עובר על כל הפוסטים, בוחר מדפים שמתאימים למה ששמרת, ומסכם כל אחד במשפט. בערך דקה לכל 100.
3. **הספרייה:** נפתח הדף `library.html` במחשב. אפשר לחזור אליו מתי שרוצים, גם בלי רשת.

| מה מקבלים | איך זה נראה |
|---|---|
| קיר של כל השמורים שמתפרק לכוננית | פתיחה של 6 שניות, אפשר לצלם ולשתף |
| חיפוש בכל השמורים | הספרים המתאימים נדלקים בכוננית |
| "שווה לעשות מזה" | עד 15 דברים מעשיים, עם סימון שנשמר |
| מדף לכל נושא | משפט לכל פוסט וקישור לפוסט המקורי |
| כרטיס לשיתוף | תמונה מוכנה לסטורי |

## חשוב לדעת
הסיכומים נכתבים בידי AI ועלולים לטעות. נקרא רק הכיתוב של כל פוסט, לא מה שנאמר בסרטון. לפני שעושים משהו, כדאי להציץ בפוסט המקורי.
